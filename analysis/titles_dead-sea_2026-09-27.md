# 死海文書の題名 — 市場で何が伸びているか

調査日: 2026-09-27 / 生データ: `analysis/data/dead-sea_titles_2026-09-27.csv`（324本）

## やり方

- YouTube 検索（yt-dlp、日本語表示）で15通りの語（死海文書／＋ゆっくり解説・都市伝説・予言・AI・解読・バチカン・
  救世主・人類滅亡・エヴァ・聖書・イエス、死海写本、クムラン）を各80件。仮名を含み「死海」か「クムラン」を含む題だけ残した。
- 各チャンネルのページから登録者数と、直近30本（公開2週間未満を除く）の再生数の中央値を取った。
- **平常比** = その動画の再生数 ÷ そのチャンネルのふだんの再生数。登録者の多さで伸びたのか、題と題材で伸びたのかを分ける。
  中央値1,000回以上のチャンネルの102本で比べた（エヴァのパロディ動画を量産している1チャンネルは除いた）。

注意: 検索に残ったものだけを見ている（生存バイアス）。動画ページは429で取れず、公開日は分からない。古い動画ほど
再生が積もっている。要素ごとの本数は少ない（4〜30本）。傾きの目安であって、法則ではない。

## 市場の形

再生10万以上は30本。上位は2種類に分かれる。

**A. 都市伝説型（大半）** — 大きなチャンネルが「判明」「禁断」「救世主」「予言」で押している。
- 64.8万 死海文書のメシアの正体が判明しました...人類滅亡の予言の真実と日本で発見された実在する救世主の痕跡【都市伝説】
- 52.0万 絶対に解読してはいけない『死海文書』の暗号…世界がひっくり返る〝隠された救世主〟の存在がヤバすぎる！！
- 52.0万 死海文書に記された、救世主の正体が遂に判明しました。絶対に解明してはいけない死海文書の真実がヤバすぎる…（平常比 68倍）
- 45.9万 【ゆっくり解説】死海文書で予言された人類滅亡はもうすぐ来る！？そのとき現れる救世主はやはり日本人だった！？（63倍）
- 16.7万 死海文書のDNA鑑定で判明した衝撃の事実（41倍）
- 21.8万 【総集編】最新AI解析で解読された世界の古代文書…ヴォイニッチ手稿と死海文書から判明した衝撃の真実（27倍）

**B. 実物への好奇心型（少数だが最大の当たりを含む）** — 嘘の主張をせず、物そのものの面白さで引いている。
- 101.0万 死海文書はあなたが思っている以上に奇妙なものだ
- 53.0万 死海文書　そして文書だけが残った…
- 32.2万 洞窟で見つかった『死海文書』がスゴすぎる｜コレただの厨二向け単語じゃないんです！

読み: 市場が欲しがっているのは「**封じられていた文書が解読され、救世主（か予言）について決定的なことが分かった**」という

## うちが使えるもの、使えないもの

上位の約束（「正体が判明しました」「日本に実在する救世主」）は、資料で確かめると成り立たない。台本の結論も
「救世主の正体は書かれていない」。**同じ語を、問いの形で使う。** 参考chが140万回を取った題
「【AI解析でどこまで分かったのか】奇書ヴォイニッチ手稿解読の600年」も、需要の語（AI・解読）を、知識の限界を問う形に入れている。

台本（drafts/dead-sea.txt）で言っていて題に使える事実: 救世主の記述はあるが正体は書かれていない（4章）、AIで135点の年代が
推定された（3章）、DNAで断片の動物と組み合わせが分かったが書いた人は分からない（5章）、バチカンが隠した証拠は無い（1章）、
今の旧約聖書と同じ系統の本文は35%（2章）、それまでの最古の写本より1,000年古い（冒頭）。
使えない事実: 「60年古かった」（資料にはあるが台本から落ちた。使うなら3章に一文足す）。

## 題の候補（推し順）

1. **死海文書に「救世主の正体」は書かれていたのか【AI・DNA解析でどこまで分かったのか】**
   市場で最も伸びる約束（救世主の正体）を問いにし、参考chの当たった括弧の型と AI・DNA を足す。題材名が先頭。
2. 「禁断の書」死海文書は本当に解読されたのか【救世主の正体・バチカン隠蔽・AI解析を論文で検証】
   効きの一番強い「禁断」「解読」を、呼び名（かぎ括弧）と問いにして使う。長い題も市場では通っている（60字超の題の平常比 8倍）。
3. 洞窟で見つかった2000年前の聖書、死海文書に「救世主の正体」は書かれていたのか
   B型（実物への好奇心）。題材を知らない人にも何の話か分かる。
4. 死海文書、今の聖書と同じ系統は35%だけだった【救世主の正体は？ AI・DNA解析で検証】
   台本の中でいちばん意外な本当の数字を先に出す型。

サムネの文字: 大きく「救世主の正体は？」、小さく「AIとDNAで確かめた」。

## 題と冒頭をそろえる

題で「救世主の正体」を約束したら、最初の30秒でその話が出てこないと離脱する。いまの冒頭で見せている題名の例は
「バチカンが隠した」と「AIが暴いた」の2本で、救世主は4章（7分台）まで出てこない。1か2を使うなら、冒頭の例に
「死海文書に記された救世主の正体が判明しました」を足す。

## 自動化した（2026-09-27）

Write approved が題材ごとに同じ集計を取り、題名の案まで出す。

1. `topic_scout.market`: 題材名で検索 → 題によく出る語を足してもう一度検索（計7回）→ 各チャンネルの
   ふだんの再生数 → 平常比 → 語ごとの効き。1チャンネルが量産した語は数えない（3チャンネル以上）。
   本数の少ない語は1倍に寄せる（4本で7.4倍のメシアは2.7倍として扱う）。`reports/<名前>_market.json`
2. 主張の選び方: 仕様に渡す「いま語られている話」を、平常比の高い順に並べる。
3. 冒頭: 冒頭で見せる題名の例を、題で約束する話（いちばん効く語を含む章）から先に選ぶ。
4. 題名の案（`titles.market_propose`）: 章の問いを題にし、効く語で点を付ける。
   - 効く語は台本が話しているものだけ。「判明しました」のような言い切りは作らない
   - 効く語を並べても、2つ目からは半分しか数えない。括弧の中の列挙は減点（参考chのピラミッド回）
   - 「？」「謎」「最新研究で」は、その題材で効いているときだけ足す
   - 題で約束する話が冒頭に出てこなければ注意を出す
5. 出る場所: Issue のコメント（上位3つ）、Make video の `out/<名前>_titles.txt`

題材によって効く語は逆になる。ヴォイニッチ手稿では「とは」「？」「謎」が効き、「AI」は30本が使っていて
差がつかない（0.81倍）。死海文書では「謎」「隠された」は効かない。決め打ちの語の表では安定しない。
