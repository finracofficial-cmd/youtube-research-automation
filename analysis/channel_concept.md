# 工程Aが出したテーマと、それに基づくチャンネル設計

前提: 38題材の検索 → 量産系チャンネル45を走査（2,400本のタイトル）→ 候補77語 → 採点。

---

## 1. 結論：使える脈は「古代ミステリー」ほぼ一本

未解決事件・日本史・科学・生物・宇宙・怪奇の17脈を追加投入したが、
**「狙う」判定は1件も増えなかった**。理由は全部「空白ゼロ」。

| 脈 | 代表題材とスコア | なぜ落ちるか |
|---|---|---|
| 科学・物理 | ブラックホール0.00 / 太陽系0.00 / 物理学0.00 / 遺伝子0.00 / アインシュタイン0.00 | まともな科学chが既に長尺で押さえている |
| 日本史 | 縄文人0.00 / 古事記0.00 / 法隆寺0.20 / ザビエル0.19 | 同上（歴史系の良質chが厚い） |
| 宇宙開発 | ボイジャー0.13 / アルテミス計画0.20 / アポロ計画0.24 | 同上 |
| **古代ミステリー** | **オーパーツ0.60 / 地上絵0.61 / スフィンクス0.58** | **供給が丸ごとゆっくり・オカルト。空白1.00** |

**この帯だけ、供給が100%量産系に占領されている。** だからここにしか裁定が残っていない。
「未解決の謎なら何でもいい」は成立しない。**チャンネルは古代ミステリーに寄せる必要がある。**

## 3. 発掘の穴（重要）

**ダイアトロフ峠事件はシードに入れたのに発掘されなかった。**

理由は、走査した45チャンネルの直近60本に「ディアトロフ」が3ch以上で現れなかったため。
**discover は「いま量産chが繰り返し擦っている題材」を拾うので、
需要は巨大だが今トレンドではない題材を取りこぼす。**

→ discover（自動発掘）と、手で入れた候補の scout（採点）は**併用する**。
   discover は補充用、手動候補は当たりを逃さないため。

## 4. チャンネル・コンセプト

### 中核の約束（1文）

> **「その話、最初に言い出したのは誰か」を一次資料まで戻って確かめる。**

これは思いつきではなく、ピラミッド回で実際に使われて機能していた言い回しをそのまま軸にしている:
「いま語られている話には、最初に言い出した人がいる。その名前も、言った年も、記録に残っている」

### なぜこの形にするか

1. **ジャンルではなく手続きを約束にする。** 題材は毎回変わるが、やることは同じ。
   視聴者から見て「さっき観たやつと同じもの」が並ぶ＝カタログが揃う
2. **コメントが証明した需要にそのまま答える。**
   「取るに足らない動画が多い中で、こちらは全く違う」「考察ではない、あくまで事実の列挙」
   「トンデモ本も読んだけど科学的根拠が無さすぎるものは楽しむのにも限界がある」
   → 求められているのは新しい謎ではなく、**同じ謎の誠実な扱い**
3. **競合が絶対に真似できない。** 量産chは「ついに解読！」と言わないと成立しない。
   「確かめられていない」と言い切れることが、そのまま差別化になる

### やらないと決めること（＝ブランドの実体）

- 結論を先に決めて資料を集めない
- 「ついに解読」「衝撃の真実」を使わない（競合の語彙をそのまま避ける）
- 一次資料に当たれない題材はやらない
- **元チャンネルの失敗を踏まない**: 1本目が「橋本環奈の息分子」だったせいで、
  133万人が流入した時に関連動画がゼロだった（♥511のコメントが証拠）。
  **バズる前に同系統を5本以上並べておく**

### 概要欄ドラフト

```
都市伝説として語られている話を、論文と一次資料まで戻って確かめるチャンネルです。

「ピラミッドは真っ白だった」「地下に巨大な空間がある」「あれは人間には作れない」。
こうした話には、必ず最初に言い出した人がいます。
その名前も、言った年も、たいていは記録に残っています。
そこまで戻って、何が確かめられていて、何が確かめられていないのかを分けます。

【扱う基準】
・いま都市伝説として大量に語られていること
・一次資料が実在すること

【やらないこと】
・結論を先に決めて、それに合う資料だけ集めること
・「ついに解読」「衝撃の真実」のように、確かめられていないことを確かめたように言うこと

出典はすべて概要欄に置きます。
査読を通っていない資料や、撤回された論文を扱うときは、その旨を明記します。
画像のライセンスと、AI生成の映像を使った箇所も明記します。

調べてほしい話があれば、コメントで教えてください。

#都市伝説 #検証 #一次資料
```
