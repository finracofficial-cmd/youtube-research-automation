## 本編の駆動原理：オープンループ連鎖

**幕の末尾で必ず閉じて、即座に次を開く。** 52分で5回、これが起きている。

```
03:41  さて、ここまでが絵の話だ。
03:44  では文字はどうなのか。                        ← 閉じて即開く

11:31  ここまでがこの本が何なのかの話である。
11:34  15世紀に作られた。
11:37  ヨーロッパで作られた。
11:37  そして少なくとも1622年にはプラハにあった。
11:43  分かっているのはそれだけだ。                  ← 3つ列挙して「それだけ」で落とす
       では中身はどうなのか。                        ← 次を開く

19:11  ここまでが素人の挑戦である。
19:11  そしてプロが来る。ウィリアム・フリードマン。   ← 人物の登場で開く

25:22  ここまでが気持ちのいい話である。
25:25  ここからがこの章の本題だ。                    ← トーンの反転を宣言

36:57  さてここまでがAIが到来する以前の話である。
37:00  16年。この本の研究に機械学習が入ってくる。     ← 年号だけの短文で切り替え
```

型は常に同じ：**「ここまでが〜」で閉じ、「では〜」「そして〜」「ここからが〜」で開く。**

閉じるときに**3つ列挙して「それだけだ」で落とす**のが繰り返し出る。
情報を与えたのに「まだ何も分かっていない」という感覚を作る手口。

### 幕の境目に置かれる仕掛け
> その壁を超えたのは、なんと日本人だった。

第3幕の直前。日本人視聴者への強いフックを、いちばん離脱しやすい幕の境目に置いている。

## 着地の4ブロック（約11.5%）

### ⑧ 一般化（5.5%）— ここが拡散の動力
> なぜAIは囲碁で人間を超え、タンパク質の形を言い当て、数学の未解決問題まで解き始めているのに、
> この1冊の本を読めないのか。
> 答えを言う。囲碁とタンパク質と数学。この3つには共通点がある。**答え合わせができる。**
> （中略）**AIの限界は賢さではない。答え合わせができるかどうかで決まっている。**

**動画の結論が、動画の題材より大きい。**
ヴォイニッチ手稿に興味がない人にも刺さる形に着地させている。
「AIの限界の話」として共有される。ここが無いと、ただの解説動画で終わる。

### ⑨ 回収（2.5%）
> 書き手が5人だと分かった。下書きはないと分かった。順番が入れ替わっていると分かった。
> **だが中身は一語も読めていない。**

「〜と分かった」を反復し、最後の1文で全部ひっくり返す。

### ⑩ 条件の提示（2.0%）
> ではいつか読める日は来るのか。来るとすれば、それは**もっと賢いAIが現れる日ではない。
> 答え合わせができる何かが見つかる日である。**

「いつか分かるでしょう」で終わらせない。**何が起きれば解決するかを具体で言う。**
⑧で出した一般化を、そのまま未来の条件に変換している。

### ⑪ CTA（1.5%）— ここだけ敬体
> このチャンネルではこういう疑問を検証・解説していきます。
> 調べてほしい疑問があればコメントで教えてください。

本編は常体（である調）で通し、**最後だけ敬体に切り替える。**
語り手という役から、人間に戻る演出。

## なぜこの順番なのか

| ブロック | 解決している問題 |
|---|---|
| ①②③ | **最初の15秒で閉じられる**問題 |
| ⑤ | 視聴者が勝手に納得して離脱する問題 |
| ⑥ | 長尺を「あと何分あるのか分からない」と感じる問題 |
| 本編の連鎖 | 5分ごとに集中が切れる問題 |
| ⑧ | 観終わった人が誰にも話さない問題 |
| ⑩ | 「結局分からないのかよ」で終わる問題 |

**どのブロックも離脱対策になっている。** 52分という尺は、この構造があって初めて成立する。

## 実装との対応

`script_engine/beats.py` がこの11ブロックを比率つきで持っている。
`python -m script_engine prompt <題材>` で、題材を差し替えた同じ骨組みが出る。

実測（n=3）では、**骨格（文長・文密度・話速）は93〜97%で再現する**。
再現しないのは肌理（数字密度・短文のリズム）で、これは調査の歩留まりに依存する。
