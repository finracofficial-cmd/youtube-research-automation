# 参考chのフレームを実際に見て分かったこと

動画単体の取得はbot判定で弾かれていたが、`player_client=web_safari` なら通る。
ストーリーボード（YouTubeが持つ間引きフレーム）を落とせば構成が一望できる。

    yt-dlp --extractor-args "youtube:player_client=web_safari;lang=ja" -f sb0 <url>

ヴォイニッチ手稿回（52分）324コマ、ピラミッド回（38分）234コマを確認した。

## 1. 構図の仕組みがこちらと根本的に違う

| | 参考ch | こちら |
|---|---|---|
| 背景 | ほぼ黒。写真は**中に浮かぶ札** | 写真を全面に敷いて暗くする |
| 画の切り替え | 1枚を**30〜60秒持たせる** | 8秒ごとに切る |
| 札の出し方 | 1枚ずつ**積み上がる** | 出ては消える |
| 出典 | **左下・極小・常時**、ライセンス込みの1行 | 左上・中くらい |
| 周辺減光 | 全カットで四隅が落ちている | 無し |

とくに「1枚を持たせて札を積む」が効いている。こちらは8秒ごとに画を替えて
札を1枚ずつ出しては消すので、密度が上がらない。

## 2. 「題材の動画」の正体

参考chが乗せているのは、拾ってきた映像ではなく**自分で作った3D**だった。
フレームに出典表記がそのまま写っている:

- `3D model · 146 m · lettering after the written accounts only`（灰色の
  ピラミッドに寸法線と「146m」）
- `3D model of the Edinburgh stone · 35 × 52 × 55 cm (Lightbody, JAEA 2, 2016)`
  （灰色の直方体に「52.37cm / 1 cubit」）
- `3D reconstruction (Blender) of the backyard experiment · G. Dash, JAEA 2 (2017)`
- `AI-generated reconstruction (from ch.0) · descending passage`（AI生成と明記）

Commons から動画を拾う道も試したが、実測で使えない。
古代遺跡系12記事・素材242点のうち**動画は1点**だけだった。
（Stonehenge / ギョベクリ・テペ / バールベック / イースター島 / ナスカ /
 ギザ / ヴォイニッチ / 死海文書 / マチュピチュ / 与那国 / シュメール = 0点、
 アンティキティラのみ1点）

結論: **探すのではなく作る。** 寸法線つきの立体、積み上がる図、動く地図。
Remotion で作れるものばかりで、出典の心配も無い。

## 3. 図の作り方

- 折れ線は**1点ずつ増える**。横軸のラベルが写真の小さな札になっている
  （ピラミッド6基の写真が軸ラベル）
- 研究者の比較は**札の列**。Petrie 1883 / Dorner 1981 / Spence 2000 /
  Isler 1989 / Dash 2017 が並び、✓ と ? が切り替わる
- 天秤の図で「意味のある文章」と「まったくのデタラメ」を比べる
- 章カードは全画面。第9章は緑の文字が降る背景（題材に寄せた演出）
- 画面下に**進捗バー**があり、赤い印と「ここから最後の話」が出る
