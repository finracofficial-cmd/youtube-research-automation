# 参考chの編集密度（実測）

## 取得方法

動画本体はボット判定で取得できなかったが、**ストーリーボード**（YouTubeが配信する
サンプリング済みフレーム格子）は `mweb` / `web_safari` クライアントで取得できた。

```bash
yt-dlp --extractor-args "youtube:player_client=mweb" -f sb0 -o "sb.%(ext)s" <URL>
```

36シート × 3×3グリッド = **324フレーム / 9.8秒間隔 / 52分39秒の全体**。
解像度は320×180。細部は読めないが、パネルの有無と配置は判別できる。

## オーバーレイ被覆率

写真は全面にテクスチャがあるが、UIパネルは「長く平坦な帯」を作る。
その帯を持つ行の割合をスコアにした（`detect.py`）。
較正: 自分の出力で、パネルありが0.19〜1.00、画と字幕のみが0.000。
**字幕だけでは反応しない**ので、検出＝パネルである。

| 閾値 | 該当フレーム | 割合 |
|---|---|---|
| 0.05以上 | 263 / 324 | **81.2%** |
| 0.10以上 | 217 / 324 | **67.0%** |
| 0.20以上 | 167 / 324 | 51.5% |

パネルが全く無いフレームは **29枚（9.0%）だけ**。

時間帯別（閾値0.10）: 0〜13分 72.8% / 13〜26分 59.3% / 26〜39分 70.4% / 39〜53分 65.4%。
**全編を通して安定して高い。** 序盤だけ凝っているわけではない。

## 自動組版との差

| | 参考ch（実測） | 現在の自動組版 |
|---|---|---|
| オーバーレイ被覆率 | **67%** | **6.6%** |
| パネル無しのフレーム | 9% | 93% |
| 同時表示 | 複数（人物＋パネル＋字幕など） | 1個まで |

**約10倍の開き。** 「出しすぎると読めない」と考えて密度を抑えたのは設計判断の誤りだった。

## 実装していない部品（モンタージュから確認）

324フレームを目視した範囲で、こちらに無い型が複数あった:

- **データチャート** — 減衰曲線に「100.0%」「93.0%」の数値を添えたもの
- **タイムライン／進捗バー** — 区切りのある横バー
- **格子・行列表示** — 文字頻度表のようなグリッド
- **人物インサート** — 肖像＋氏名ラベル＋年号
- **大きな数値の単独提示** — 「600枚」「約4,726万円」「純金 3.494 g」「×58」
- **単一文字の巨大表示** — 写本の1文字を画面いっぱいに
- **粒子・降下アニメーション** — 背景に流れる文字列

現在あるのは引用カード／チップ／カード列／論文カードの4種のみ。

## 示唆

差は「作り込みの丁寧さ」ではなく**部品の種類数と出現頻度**にある。
どちらも足せる性質のもので、根本的に真似できない類のものではない。
ただし中身（どの数値を、どのタイミングで出すか）は調査の産物なので、
台本から機械的に抜けるものには限りがある。
