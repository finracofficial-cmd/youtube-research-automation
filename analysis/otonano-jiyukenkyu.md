## 2. 結論：バズった理由は「作り」ではなく「題材選定」

**決定的な証拠は1本目にある。**
橋本環奈回は3本中もっとも高評価率が高い（3.48% = ヴォイニッチの3.3倍）。
つまり**観た人の満足度は1本目が最高**。それなのに再生数は100分の1。

制作フォーマットは3本とも同一（後述の「型」は3本で完全に一致）。
品質が同じで結果が100倍違う以上、**差分は題材の需要しかない**。

### バズった1本だけが満たしていた3条件

| | 既存需要 | 供給の質 | 時流ワード | 結果 |
|---|---|---|---|---|
| 橋本環奈の息分子 | **ゼロ**（誰も検索しない） | － | なし | 1.2万 |
| ヴォイニッチ手稿 | **巨大**（ゆっくり解説が多数存在＝実証済み） | **低い**（ゆっくり・都市伝説のみ） | **AI** | 133万 |
| ピラミッド | 巨大 | **高い**（大手が何本も出している激戦区） | AI | 3.3万 |

- **(a) 既存需要の実証**: ヴォイニッチ手稿は【ゆっくり解説】系が何本も存在する = 検索・ブラウズ需要が証明済みの題材
- **(b) 供給の空白**: しかし供給は全部ゆっくり解説。「一次資料に当たった52分のドキュメンタリー」は存在しなかった
- **(c) 時流ワードの接続**: 「AI」。タイトル【AI解析でどこまで分かったのか】、サムネ「**AIが敗北**」

競合の勝ちタイトル「ついにAI解析でここまで判明！ヴォイニッチ手稿の謎【ゆっくり解説】」(2025/12) を
【AI解析でどこまで分かったのか】へほぼ踏襲している。**先に勝ちタイトルを調べてから作っている。**

> つまり狙うべきは「需要が実証済み × 供給が低品質 × 時流ワードが刺さる」の三重積。
> ピラミッドが伸びなかったのは (b) を外したから（大手激戦区に正面から入った）。

## 3. 再現可能な「型」の分解

### 3-1 冒頭90秒テンプレート（3本とも完全に同じスロット構造）

| スロット | ヴォイニッチ（133万） | ピラミッド |
|---|---|---|
| ①体言止めの一撃 | 「ヴォイニッチ手稿。600年間誰にも解読できていない書物である。」 | 「ピラミッド。」 |
| ②異様さの具体列挙3つ | 見たことのない植物／緑の水に浸かった裸の女性たち／どの言語とも一致しない文字 | 人もカメラも入れていない空間／決まらない石の運び方／地下の巨大空間 |
| ③**チャンネル宣言（固定文）** | 「当チャンネルでは都市伝説は語らない。一次資料だけを積み上げ、あくまで科学的に迫っていく」 | 「当チャンネルでは、こうした未解決の謎を、都市伝説として語るのではなく、論文と一次資料からひも解いていく」 |
| ④全体の地図を先に開示 | 「話は4つに分かれる。第1幕…第2幕…第3幕…第4幕」 | 「当たっていたもの→理由が違うもの→跡形もなくなるもの、の順に並べた」 |
| ⑤**出発の合図（固定文）** | 「それでは私と共に、世界最大の謎の1つに迫っていこう」 | 「それではさっそく、私と共に、ピラミッドの真相へと迫っていこう」 |

**自己紹介・挨拶・BGM尺ゼロ。1秒目から本題。** ③と⑤は一字一句に近い固定文＝完全にテンプレ化されている。

### 3-2 章構成 = オープンループの連鎖（最大の発明）

ピラミッド回で全章の末尾を検証したところ、**例外なく「次章の問い」で終わっている**：

```
1章末「奴隷なのか。国民だったのか。はたまた宇宙人だったのか。」  → 2章へ
2章末「その人たちが積み上げたものは、真北をほぼ正確に指している」→ 3章へ
3章末「ここまでの三つは都市伝説の言うとおりだった。次の章から少し形が変わる」← 幕の切替宣言
4章末「それなのに、いちばん素朴な問いにはまだ答えが無い。あの石はどうやって運ばれたのか」→ 5章へ
7章末「査読を通った論文が、ちゃんとあった」                      → 8章へ
8章末「さて、最後の話に行く。1章で保留にした問いだ」              ← 30分越しの回収
```

さらに **1章で「宇宙人については最後の章で扱う」と宣言して9章で回収**＝**30分の長距離オープンループ**を張っている。

加えて「**ここまでが〜の話である。では〜はどうなのか**」という締め＋再起動が52分で**10回**出現。約5分に1回、注意をリセットしている。

**信頼度グラデーション設計**（ピラミッド）:
`都市伝説が正しかったもの → 正しいが理由が違うもの → 一次資料で跡形もなくなるもの`
最初に視聴者の信念を**肯定**してから、徐々に反転させる。都市伝説層を科学側へ連れてくる導線。

### 3-3 文体（字幕全文からの実測値）

| 指標 | ヴォイニッチ | ピラミッド |
|---|---|---|
| 平均文長 | **21.6字**（中央値19字） | 21.0字 |
| 文の数 | 860文 / 52分 = **3.7秒に1文** | 685文 |
| 話速 | 358字/分 | 380字/分 |
| 常体（である/だ） vs 敬体 | **161 : 2** | ほぼ全て常体 |
| 疑問文 | 1.0% | ほぼなし |
| 視聴者への語りかけ | ほぼゼロ | **1件のみ** |
| 数字の出現 | **7.9個/分** | 33件 |
| 留保表現「ただし」等 | 多用 | **24回** |

- **1文=1事実の短文連打**。「次が天文。」「縁が並ぶ。」「低すぎる。」のような体言止め・4〜6字の文を混ぜて緩急を作る
- **「皆さんどう思いますか？」的な馴れ合いが一切ない**＝ドキュメンタリーの語り。ゆっくり解説との最大の差別化点
- 難語は必ず日常比喩に着地：「エントロピーという量がある。難しそうな名前だが中身は皆さんが毎日使っているものと同じである。**スマホの予測変換だ。**」
- **最後のCTAだけ敬体に切り替える**（「〜していきます」「教えてください」）＝語り手から人間へ戻る演出

### 3-4 信頼の演出装置

本編内：
- 「**私も全部見た。**」「私は今この本の全文を手元に持っている。誰でもダウンロードできる。」
- 「論文は概要欄に載せておくので、気になる方はそちらを見てほしい」
- 「**この本を扱った動画のコメント欄を1700件ほど読んだ**」← 競合リサーチをそのまま演出素材に転換
- 「289年前の翻訳者が、訳しながら、これは合わないと書いている」← 一次資料の人間化

概要欄（ここが他チャンネルとの決定的差）：
- 章ごとに出典を整理、URL 16〜32本、DOI付き
- **撤回された論文に★で撤回を明記**（Remote Sensing 14(20) → 2026/8/10撤回、撤回通知のDOIまで記載）
- 画像のCCライセンスを全点クレジット
- **AI生成映像を自己申告**（「一部の映像はAI生成（Seedance 2.5）。実写ではありません」）
- **自分の読み間違いを訂正として掲載**（橋本環奈回「13垓→130垓」）

### 3-5 サムネイル

| | ヴォイニッチ（勝ち） | ピラミッド（負け） |
|---|---|---|
| 背景 | **一次資料そのもの**（緑の水に浸かる裸婦の写本ページ）＝実物が既に異様 | CG合成（ピラミッド＋UFO＋ファラオ像） |

**勝ちパターン＝「本物の資料の異様さ」×「感情ワード4文字」。** タイトルは情報、サムネは感情、と役割分担している。

### 3-6 締めの「一般化」（共有される理由）

ヴォイニッチ回のラスト10分は題材を離れる：
> なぜAIは囲碁でもタンパク質でも数学でも人間を超えたのに、この1冊が読めないのか。
> → **「答え合わせができるかどうか」。AIの限界は賢さではない。**

**動画の結論が、動画の題材より大きい。** ヴォイニッチに興味がない人にも刺さる普遍的洞察になっているため、
「AIの限界の話」として拡散する。これが100万再生級と10万再生級を分ける要素。

## 4. TTPする際の注意点（このチャンネルの弱点）

1. **1本依存**: 総再生の96.7%が1本。チャンネルとしてはまだ成功していない
2. **登録転換率0.78%が低い**: 133万再生でも1万人。原因は上記2.5の通り**流入時にカタログが空だった**こと。
   バズは「関連動画が最低5〜10本溜まってから」起こすのが正解
3. **2本目の題材選定ミス**: ピラミッドは需要は大きいが大手激戦区。4日で3.3万＝前作の2.5%
4. **コンセプトのブレ**: 1本目「どうでもいい疑問を本気で計算」→ 2本目以降「未解決の謎を一次資料で」。
   バズった動画のCTAでは**まだ旧コンセプトを喋っている**（＝ヴォイニッチのヒットは本人にとっても事故に近い）
5. **制作コストが重い**: 概要欄のDOI 32本を実際に読む工程は自動化しづらい部分

## 5. 自動化の見立て（次フェーズの論点）

型の分解結果から、工程は3層に分かれる。

| 層 | 内容 | 自動化適性 |
|---|---|---|
| **A. 題材選定** | 「需要実証済み × 供給低品質 × 時流ワード」の三重積を探す | ◎ 最重要かつ最も自動化が効く（競合のタイトル・再生数・本数を機械収集して空白を探す） |
| **B. 脚本** | 冒頭90秒テンプレ／章末オープンループ連鎖／21字短文・常体・数字7.9個/分 | ○ 制約が全て数値化できているのでLLMで再現可能。ただし**一次資料の検証は人間が要る** |
| **C. 映像編集** | 資料画像の切替＋Ken Burns＋テロップ＋BGM。話者はナレーションのみで顔出しなし | ◎ 素材がPD/CCの静止画中心なので、字幕タイムコードから機械的に組める |

**再生数を決めているのはA。** BとCをいくら自動化しても、Aを外すと橋本環奈回（満足度最高・再生1.2万）になる。
自動化の投資順序は **A → C → B** を推奨（Bは品質が直接ブランドに効くので最後）。
