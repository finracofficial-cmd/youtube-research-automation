# 他テーマでの挙動（実測）

「どのテーマでも適切な動画になるか」を確かめるため、台本3本
（オーパーツ / 巨石遺跡 / ナスカ）で同じ工程を通した。

結論。**台本構造・オーバーレイ密度・事実チェック・ライセンス表示は
テーマに依存しない。画はテーマに依存する。**

## テーマに依存しない部分

| | オーパーツ | 巨石遺跡 | ナスカ |
|---|---|---|---|
| 文数 | 258 | 234 | 323 |
| データ由来の被覆率 | 41.6% | 60.1% | 64.8% |
| テロップ込みの被覆率 | 67.0% | 67.0% | 67.0% |
| 数値カード | 21 | 39 | 39 |
| 語句テロップ | 33 | 9 | 3 |

3本とも参考chの実測値67.0%に収束する。**構成だけが台本の性質で変わる**のが
要点で、数字の多い台本（巨石・ナスカ）は実データのカードで埋まり、
テロップはほとんど要らない。テロップは密度の不足分を埋める安全弁として働く。

## 画はテーマに依存する

画はWikipedia記事から引いている。したがって上限は
**その題材が自由に使える画で記録されているか**になる。代表的な題材で確かめた。

| ジャンル | 結果 |
|---|---|
| 古代・遺跡 | ストーンヘンジ / ナスカ / ギザ / モヘンジョダロ **4件すべて各4枚** |
| 自然・宇宙 | ボイジャー1号 / マリアナ海溝 **各4枚** |
| 未解決事件 | グリコ・森永 **0枚** / 世田谷一家 **0枚** / 三億円事件は**東京都の紋章のみ** / 帝銀事件は英語版なし |
| 都市伝説 | 八尺様 **0枚** / 人面犬は英語版なし / きさらぎ駅・口裂け女は2枚だが主題そのものではない |

古代遺物・遺跡・天体は撮影が自由で写真が大量にある。現代の事件や日本の
都市伝説は、画が報道写真（著作権あり）か、そもそも存在しない。

**「一次資料に当たる」というch設計と、画が取れる題材の範囲が一致している。**
逆に言うと、現代事件系に広げるなら画像生成に頼ることになり、それは
「一次資料」の看板と衝突する。

## 他テーマで初めて出た不具合

いずれもオーパーツ1本では出なかった。

**クラスが主題の回で、主題が丸ごと検索語から消える。**
モアイ・巨石・ドルメン・メンヒルはWikidataではP279（クラス）しか持たない。
巨石遺跡の検索語は3種しか出ていなかった。画を検索で拾っていた頃に
クラスを落としていたのは、語義を区別しない検索が無関係な画を返したため。
記事から引く今はクラスの記事がそのクラスの画を返す（Moai の記事にはモアイが
載っている）ので、通してよい。代わりに活動・学問分野・図形を型で落とす。

**器の判定が部分一致だった。** Stonehenge は併設展示施設由来の
`history museum` が型に混ざり、型が1つでも器なら器としていたため落ちていた。
マリアナ海溝は `oceanic trench` の `ocean` に当たっていた。

**地名の接尾辞1文字を落としていた。** 「イースター島」が「イースター」に切れ、
復活祭の記事の画が採られていた。

**図解が全画面に出る。** ナスカの回で米地質調査所の地下水断面図が出た。
題材としては近い（ナスカの地下水路）が、英語のラベルが敷き詰められていて
字幕と競り合う。図解・地図・断面図は写真の後ろに回す。

**1カットの取得が終わらない。** 巨大なスキャン画像が並ぶ記事に当たると
1カットで何分も止まった。試行数と時間に上限を置いた。

## 残っている弱点

**検索語の3〜4割は通りすがりの一般語**になる（巨石のRadar・Replica、
ナスカのComputer・Dresden・Persuasion）。影響はその区間だけで、
主題が尺の大半を占めるので致命的ではないが、ゼロではない。

**語が起きるのは区間の4〜5割**（29/67, 29/65, 33/69）。台本の本文は主題を
代名詞で受けるため、名前が書かれた区間でしか語が起きない。残りは
前の主題を引き継ぐので題材は合っているが、1つの記事の画を回して使う。
